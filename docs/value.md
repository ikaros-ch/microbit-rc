# Value

Slider position 0..100, single-axis stick -100..100 (up/right positive), or 0/1 for buttons and toggles.

```sig
gamepad.value("S")
```

## Parameters

* **id**: the widget ID set in the app

## Example

```blocks
gamepad.value("S")
```
