# Show text

Show text on every display widget bound to this channel. Use English letters only: the micro:bit can't store Greek letters in text.

```sig
gamepad.showText("msg", "hello")
```

## Parameters

* **channel**: the display channel set in the app
* **text**: 

## Example

```blocks
gamepad.showText("msg", "hello")
```
